## 附：这份提示词为什么这么写

- **先堵路再给路**：这个项目最大的成本不是“没找到方法”，是“反复重试已死的方法”。
  所以把“别做什么”放在最前面，比列一堆待办更有用。
- **给三关而不是给指标**：具体阈值会过时，“去重复计数 / 可执行性 / 样本外”这三关不会。
- **把本金口径写死**：10 万 vs 24 万的 1pp 差异，曾让一整个结论（−1.4% 超额）失真。
- **先探针后回测**：龙虎榜那次用一小时就排除了一个 t=46 的“强信号”，
  而按老流程（先建回测再跑 12 起点）要花一天。
