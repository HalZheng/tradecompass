# 交易决策状态机设计（v1）

> 替代原先"条件找买点 + 固定持有期"的无记忆结构。
> 核心变化：**仓位是决策输出**，市场环境、行业强度、交易历史都进入状态。

## 0. 为什么换结构

原结构（已证伪，见 D019/D020/D023）：

```
每天：if 条件 then 买（等权/固定） → 持有 N 天 → 卖
```

三个致命缺陷：

1. **无记忆**——昨天止损了，今天照买不误；
2. **无视大盘**——指数跌 20% 时仍然满仓；
3. **仓位恒定**——好机会和差机会买一样多。

新结构把这三点都变成状态的一部分。

---

## 1. 三层架构

```
市场层（今天最多能拿几成仓）
   ↓ 给一个 0–100% 的总额度
行业层（钱能投哪些行业、每个行业上限）
   ↓ 给出可买集合与行业权重
个股层（这只票该不该买、买多少、什么时候减）
   ↓ 输出：目标权重 + 触发价
```

三层的输出**相乘**得到最终仓位：

```
个股目标权重 = 市场额度 × 行业权重 × 个股状态权重
```

任何一层给 0，就不买。市场层给 0，全账户空仓。

---

## 2. 市场层：决定总仓位上限（对应原 M5）

**输入**（全部来自指数日线/周线，每日收盘后计算）：

| 指标 | 含义 |
|---|---|
| 沪深300 收盘 vs MA20w / MA60d | 中期趋势方向 |
| 沪深300 20 日涨跌幅 | 中期动量 |
| 中证1000 / 沪深300 相对强度（20 日） | 大小盘风格 |
| 指数 20 日实现波动率（分位） | 风险温度 |
| 全市场上涨家数占比（宽度代理：可用指数成分近似或跳过） | 广度 |

**状态与额度**：

| 状态 | 判定 | 总额度 |
|---|---|---|
| `RISK_ON` | 沪深300 > MA20w 且 MA20w 向上 且 20 日动量为正 | 100% |
| `NEUTRAL` | 站上 MA20w 但动量走平，或动量正但跌破 MA20w | 60% |
| `RISK_OFF` | 跌破 MA20w 且 MA20w 向下 | 25% |
| `PANIC` | RISK_OFF 且 20 日跌幅 > 8% 或波动率分位 > 80% | 0%（空仓） |

**记忆项（防抖 + 防打脸）**：

- 状态切换需连续 2 个交易日确认，否则维持原状态；
- 从 `PANIC` 回升到 `RISK_OFF` 需要指数站上 MA10；
- 距上次 `PANIC` 不足 10 个交易日，额度上限压到 50%（防止恐慌后立刻满仓）。

---

## 3. 行业层：决定能买什么

行业池用**中证一级行业指数**（10 个，已验证可取自 baostock：000928 能源、
000932 消费、000933 医药、000935 信息等），也可切换为用户自选的行业 ETF。

**输入**：每个行业指数 20 日动量、是否站上 MA20、动量排名变化。

**输出**：

- 可买集合 = 动量排名前 `top_k`（默认 3）且站上 MA20 的行业；
- 单行业权重上限 = `1 / top_k`（默认 33%）；
- 若所属行业不在可买集合 → 个股层不准入场（即使个股信号成立）。

**记忆项**：

- 行业排名连续 2 日跌出前 `top_k` 才剔除（避免排名抖动导致频繁换）；
- 该行业上次交易若亏损，本次入场门槛提高（要求排名前 `top_k - 1`）。

## 4. 个股层：状态机（核心）

### 4.1 状态

| 状态 | 含义 | 权重（× 基础仓位） |
|---|---|---|
| `FLAT` | 空仓观察 | 0 |
| `PROBE` | 试探仓 | 0.5 |
| `HOLD` | 正常持有 | 1.0 |
| `REDUCE` | 减仓中 | 0.5 |
| `COOLDOWN` | 止损后冷静期 | 0 |

### 4.2 转移条件

```
FLAT → PROBE
  个股：周线多头（收盘>MA20w 且 MA20w 向上）+ 日线触发（收盘>MA5 且>前日高）
  行业：在可买集合内
  市场：额度 > 0
  历史：不在 COOLDOWN；连续亏损 < 3
  记忆：若上次该票交易亏损，要求周 J < 25（更严）；否则 J < 40

PROBE → HOLD
  买入后 3 个交易日内未触及止损，且收盘创出买入后新高
  否则 PROBE → FLAT（试探失败，小亏离场）

PROBE/HOLD → REDUCE
  任一条：周线转空 / 行业跌出 top_k / 自最高回撤 > 3×ATR
  减仓卖出 50%，剩余仓位止损上移到成本价

REDUCE → FLAT
  收盘跌破 MA10 或触及成本价止损

HOLD → FLAT（止盈）
  收盘跌破 MA10 且已有浮盈 > 1×ATR
  （无浮盈时允许持有到止损，避免 D020 的"赢小亏大"）

任意 → COOLDOWN
  触发止损：冷静 `cooldown_days`（默认 5）个交易日；
  同期该票不得再入场

COOLDOWN → FLAT
  冷静期满；若连续亏损 ≥ 2，全局仓位乘数降为 0.5
```

### 4.3 个股记忆项

| 记忆 | 用途 |
|---|---|
| `entry_date` / 持有天数 | 时间止损（默认 60 日，比原来的 20 日宽松） |
| `highest_close` | 移动止盈基准 |
| `consecutive_losses` | 降低后续仓位（0.5 乘数） |
| `last_exit_reason` | 止损出场后提高再入场门槛 |
| `probe_count` | 同一标的试探次数，超 3 次则本轮不再试 |

## 5. 仓位计算（不是等权，也不是全仓）

```
可用资金 = 账户权益 × 市场额度
单票上限 = 可用资金 × 行业权重 × 个股状态权重
实际买入股数 = floor(单票上限 / 价格 / 100) × 100
```

约束：

- 同时持仓数 ≤ `max_positions`（默认 5）；
- 单票权重上限 = `min(市场额度 × 行业权重, 30%)`；
- 已有持仓的标的，加仓只在 `PROBE → HOLD` 时发生一次，不做金字塔加仓（先简单）。

## 6. 抗过拟合：消融实验，不搜参数

**不做参数网格。** 改为逐层叠加、看增量贡献（每一层都在样本外评估）：

| 实验 | 内容 | 要回答 |
|---|---|---|
| E0 | 基准：等权买入持有 | 什么都不做的收益 |
| E1 | 只有市场层（无行业、无个股状态） | 择时能不能降回撤 |
| E2 | E1 + 行业层 | 行业过滤有没有增益 |
| E3 | E2 + 个股状态机 | 状态机有没有增益 |
| E4 | E3 + 记忆项（冷却、连亏降仓） | 记忆有没有增益 |

**判定标准**：每一层在样本外的利润因子或卡玛比必须比上一层更好，否则该层应删除。
这样得到的是一组"每层都被验证过"的结构，而不是一堆搜出来的参数。

参数只有 12 个左右，且都有经济含义（默认值写死在代码，不参与搜索）。

## 8. 上下文打分模型（买卖共用一套上下文，阈值不同）

用户要求：买卖都要综合看 **位置 / 周期 / 量能 / 行业 / 大盘 / 当前仓位 / 历史交易**，
而不是两组各自为政的硬条件。实现方式改为**打分 + 否决 + 滞回**。

### 8.1 每只票、每个交易日的上下文向量

| 维度 | 具体指标 | 已有 |
|---|---|---|
| 位置 | 收盘价在过去 250 日区间的百分位；周 K/J 值 | 部分（J 有，百分位待加） |
| 周期 | 周线是否多头（收盘>MA20w 且 MA20w 向上）；日线相对周线的位置（回踩/超买） | 有 |
| 量能 | 量比 vma5/vma20；放量方向（涨放量 or 跌放量） | 有 |
| 行业 | 20 日动量排名、是否站上 MA20 | 有（sectors.py） |
| 大盘 | regime 状态与仓位额度 | 有（regime.py） |
| 仓位 | 该票当前权重 / 目标权重；组合总仓位 vs 额度上限 | 有（持仓） |
| 历史 | 距上次买卖天数、上次该票盈亏、连续亏损次数 | 有（状态机） |

### 8.2 决策：打分 + 否决 + 滞回

```
买入分 = 0.30×位置分 + 0.25×周期分 + 0.20×量能分 + 0.15×行业分 + 0.10×大盘分
卖出分 = 同一套上下文，但各项含义反向（高位/量能背离/行业跌出/大盘转差 得高分）
```

- **买入**：总分 ≥ 0.65 且无否决项
- **卖出**：总分 ≤ 0.35 或触发否决项
- **0.35–0.65 之间：什么都不做**（滞回区，这是"卖点不敏感"的正解，
  不是靠放宽某条指标实现）

**否决项（任一成立即不可买）**：大盘 PANIC / 行业不在可买集合 /
该票权重已达上限 / 处在止损冷却期 / 连续亏损 ≥3。

**卖出否决（任一成立立即减仓）**：浮亏超 max_stop_pct / 周线转空 /
组合总仓位超市场额度 20% 以上。

### 8.3 为什么这样抗过拟合

- 维度固定 5 个、权重固定（写在代码里，不参与搜索），可调参数只有两个阈值；
- 阈值改动对结果的影响是**连续**的（不像"J<15"这种悬崖式条件）；
- 滞回区天然降低换手，减少成本噪音对结论的干扰。
