# 动态调仓时机（Timing Overlay）设计与验证方案

> 2026-10-28。目标：把“防御 60 日、其余 20 日”的固定调仓日，改成**基准时钟 + 条件加速**：
> 平时按基准周期走；当多维度信号足够强时，允许**提前**动作；但永远不因为“今天排名变了”就动。
> 本文只定设计与验证方案，**不改默认策略**；回测通过才合入。

## 0. 先说清楚一个已实测的坑

“每天重排”已经试过：把保留线的检查从每 20/60 日改成每天，6 起点年化 **8.4% → 1.1%**，
超额 +2.3% → −5.0%，换手 11.5x → 21.4x；只改卖出（3 起点）也从 9.4% 掉到 2.0%。

原因不是成本，是**20 日持有期本身就是因子收益的一部分**。20 日反转/价量因子需要时间兑现，
每天检查等于把“正常回撤”当成“趋势破坏”，把右尾砍掉。

所以本设计的第一条原则：**不允许“每天重新排名”**。只允许在基准时钟之外，加一层
**条件触发的提前动作**，而且触发条件必须是“多指标共振”，不是单一排名变化。

## 1. 设计原则

1. **基准时钟是默认，加速是例外。** 防御 60 日、其余 20 日的调仓日不变；没有触发就等到期。
2. **只提前，不延后。** 触发只让动作更早，不会让到期该做的事推迟。
3. **非对称。** 卖出看风险（高位、反转、放量、行业转弱、浮盈回吐）；买入看机会
   （不在高位、行业向上、大盘不恐慌、分数明显高于买入线）。两边的指标和阈值分开。
4. **提前只做一半。** 提前卖出卖 50%，剩下 50% 留给基准日；提前买入买半个名额。
   这样即使提前判断错了，也只错一半，不会把右尾一次性砍掉。
5. **频率治理优先于信号。** 再强的信号，也要过“每票最小间隔 / 每月次数 / 换手上限”三道闸。
6. **个人状态是闸门，不是信号。** 持仓数量、浮盈亏、最近成交只决定“能不能动/怎么动”，
   不参与打分，避免把“不想卖”包装成“信号不强”。

## 2. 卖出加速（Risk Exit）

**适用对象**：仍在保留线内、但出现风险共振的持仓（已经跌出线的走基准清理，不重复触发）。

| 指标 | 触发条件 | 经济含义 |
|---|---|---|
| 位置 | `pos250 ≥ 85` | 过去一年高位，回撤空间大 |
| 反转 | `rev5 ≤ −5%`，或 `rev20 ≤ −8%` 且 `rev5 < 0` | 短期动能转弱，不是普通波动 |
| 放量 | `量比20 ≥ 1.5` 且当日下跌 | 放量下跌，派发 |
| 行业 | 板块指数 < MA20 且 MA20 下行 | 行业转弱，不是个股问题 |
| 浮盈 | `浮盈 ≥ +15%` | 有利润可保护，避免坐电梯 |

**触发**：至少 **3 个** 指标同时成立（V1），或 **4 个**（V3，严格版）；
且 `持有 ≥ 最短持有`、`距上次提前卖出 ≥ 10 个交易日`、`本月提前卖出 < 3 次`。

**动作**：卖出 50%（V1/V3）或 100%（V2，对照）。剩余部分等基准调仓日。

## 3. 买入加速（Opportunity Entry）

**适用对象**：上一次调仓日排在前列、但因为现金/名额没买到的候选（相当于报告里的“候补”）。

| 指标 | 触发条件 | 经济含义 |
|---|---|---|
| 位置 | `pos250 ≤ 70` | 不在高位，追高空间小 |
| 行业 | 板块指数 > MA120 且 MA20 上行 | 行业顺风 |
| 大盘 | 沪深300 不是 RISK_OFF/PANIC | 不在恐慌里接刀 |
| 分数 | 上次调仓日分数 ≥ 买入线 + 0.3 | 不是边缘候选 |
| 量能 | `量比20 ≥ 1.2` | 有资金参与，不是阴跌 |

**触发**：至少 **3 个**；且 `本月提前买入 < 3 次`、`该票不在 20 日冷却期`。

**动作**：买入 **半个名额**（`slot_value × 50%`），剩下半个名额留给基准日。

## 4. 频率治理（Frequency Governor）

| 闸门 | 取值 | 作用 |
|---|---|---|
| 每票提前卖出最小间隔 | 10 个交易日 | 防止同一只票反复减仓 |
| 每票提前买入最小间隔 | 5 个交易日 | 防止追着同一只票加 |
| 每月提前卖出上限 | 3 次 | 防止一个月把组合拆光 |
| 每月提前买入上限 | 3 次 | 与“每日最多新买 3 只”同量级 |
| 最短持有 | 沿用 10/40 日 | 刚买不卖 |
| 卖出冷却 | 沿用 20 日不回补 | 卖了不追 |
| 换手上限 | 回测里报告，超过基准 1.5x 视为不通过 | 成本是当前第一约束 |

个人状态（持仓数量、浮盈亏、最近成交）只用来**放行/拦截**，不参与打分：
- 浮亏超过 20% 的票，不因为“提前卖出”信号在低位一次性割，仍走反弹条件单；
- 已满 12 个名额时，提前买入必须先有卖出回笼，不额外加杠杆；
- 最近 10 个交易日已经动过的票，不再提前动。

## 5. 与现有因子的关系（避免重复计算）

现有分组因子已经包含 `rev20`、`pv_corr20`、`turn20`、`vol60`、`ep/bp/roe` 等。
Timing Overlay **不重新打分**，只回答“现在是不是一个特别好的/特别差的执行时点”，
所以只用现有选股分数**之外**的信息：

- `pos250`：当前因子集没有，新增；
- 行业指数 MA20/MA120 与斜率：现在只用于名额倾斜（×1.3/×0.7），没有用于时机；
- 大盘 regime：现在只展示，不执行；
- 量比、5/20 日收益：用于确认，不替代选股；
- 浮盈、持有天数、最近成交：账户状态，不参与选股。

## 6. 回测方案

| 版本 | 规则 | 目的 |
|---|---|---|
| V0 | 基线：固定 20/60 日 | 对照 |
| V1 | 提前卖 50%，3/5 指标，频率闸门 | 主方案 |
| V2 | 提前卖 100%，3/5 指标 | 看“只做一半”是不是关键 |
| V3 | 提前卖 50%，4/5 指标（更严） | 看阈值敏感性 |
| V4 | V1 + 提前买 50%，3/5 指标 | 看买入加速有没有增量 |

口径：2019 年起 12 个起点、2023+ 样本外、2 倍成本、真实费率/滑点/涨跌停；
报告年化、超额、夏普、最大回撤、最差起点、卖出笔数、换手、提前触发次数。

## 7. 验收标准（不过关就不合入）

1. 12 起点均值：净超额不低于基线 −1pp；
2. 2023+ 样本外：净超额不低于基线；
3. 2 倍成本：净超额不劣化；
4. 换手不超过基线 1.5x；
5. 最大回撤或夏普至少一项改善；
6. 提前触发的交易单独统计：T+20 相对“不提前”的收益差，不能显著为负。

任何一条不过，就保留固定调仓日，把结论写进 HANDOFF §5.3（已实测否定）。

## 8. 已知风险

- **右尾**：提前卖出最大的风险是砍掉大赢家。用“只卖一半 + 4/5 严格版”对冲。
- **过拟合**：阈值（85、−5%、1.5x、3/5）都是先验，不在全样本上网格搜索；
  只做 3/5 vs 4/5、50% vs 100% 两组敏感性。
- **双重计算**：行业趋势/量能已经在选股因子里出现，Overlay 只用于确认，不重复加权。
- **执行**：提前卖出仍是条件单（反弹到 MA10/MA20），不是市价砸；回测里先用次日开盘近似，
  实盘再用条件单，两者会有差异。

## 10. 方向 A：调仓日内部的排序与“卖多少”（2026-10-28 实测否定）

### 10.1 思路

V1 失败的根因不是“信号方向错”，而是**多开了一个决策日**。方向 A 只在原有的 20/60 日调仓日
内部动两件事，不新增任何交易时点，因此不会把“正常回撤”当成“趋势破坏”，也不改变 20 日持有期：

- **卖多少**：跌出缓冲区的票，风险共振 ≥3/5 → 卖 100%，否则卖 50%。
  只卖一半的票在**下一个调仓日强制清掉余下的一半**——否则它每个周期都还在保留线外，
  会一轮一轮地再卖一半（首版没加这条，实测平均现金占比 56%、换手掉到 2.2x，明显不是设计意图）。
- **先买谁**：候选按机会分降序排列，同分保持原名次（`stable`），所以只是倾斜，不是推翻排序。
  两个力度：`全体候选`（可以跳过名次很靠前的票）和`缓冲区内候选`（只在保留线以内的候选之间排）。
- **对照 A1c**：不看分数，一律卖 50%。用来区分“分数提供了信息”和“只是把仓位降下来”。

阈值全部沿用 §2 的先验（3/5、85、−5%、1.5x），**没有做任何网格搜索**。

### 10.4 为什么又失败

**（1）风险分在“跌出缓冲区”这个时点几乎没有区分度。** 12 起点合计 4321 次卖出，
共振命中的分布是：0/5 50%、1/5 36%、2/5 12%、**3/5 只有 2%、4/5 和 5/5 都是 0%**。

这和 V1 触发 96 次并不矛盾——两者样本不同：V1 是在**仍在保留线内、位置高、有浮盈**的票上触发；
而一只票“跌出缓冲区”时，通常已经跌过了（pos250 低、浮亏），恰好把“位置 ≥85”和“浮盈 ≥15%”
这两个维度打掉。所以**同一套分用在卖出时点上，等于一个常量**。

**（2）“按分数卖多少”于是退化成“一律卖半”。** A1 与 A1c 的数字几乎逐项重合
（年化 5.7% vs 5.7%、超额 −0.3% vs −0.3%、回撤 −14.4% vs −14.5%、换手 6.0 vs 5.9、
卖出 636 vs 636）——**分数的贡献 ≈ 0**。这是本次实验最干净的一条证据。

**（3）“交易次数不变”这个前提本身不成立。** 卖一半之后余下的一半要在下个调仓日卖掉，
所以卖出笔数 554 → 636（+15%，其中 276 笔是延迟清仓），买入 566 → 295（−48%）。
**名义成交额减半（换手 11.4x → 6.0x），所以“零增量成本”在金额上成立、在笔数上不成立。**

**（4）卖一半的实质是降仓，而且不划算。** 平均现金 5% → 22%，换手砍半省下的成本
抵不过少赚的：年化 8.5% → 5.7%、超额 +2.5% → −0.3%。按投入资本还原（÷0.78）年化约 7.3%，
仍低于基线 8.5%——**不只是现金拖累，留下的一半本身就是负贡献**（T+20 相对池 −1.30%，
2 倍成本下 −1.31%）。

**（5）买入侧：时机分不能替代选股排名。** 全体候选按机会分重排 → 年化 5.0%、回撤 −22.1%、
夏普 0.31；即使在“保留线以内”的候选之间重排，也只有 6.9% / −19.9% / 0.45，全面差于基线。
机会分衡量“现在是不是好的买入时点”，不衡量“哪只票更好”，而后者才是收益来源。

### 10.5 结论

**方向 A 也不成立。** 这套时机分在基准调仓日的两个可用位置（卖出比例、买入顺序）都没有增量信息：
第一处退化成降仓，第二处直接损害选股 alpha。

按 §7，A1/A1c/A1x/A2/A2b/A3 **全部不合入**。至此“动态调仓时机”的两个方向（提前触发、调仓日内排序）
